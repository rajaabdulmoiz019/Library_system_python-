This is a simple Python-based Library Management System created for beginners to understand OOP (Object-Oriented Programming) concepts in an easy and practical way.<br><br>

The project allows users to:<br>
• Add books to a library<br>
• Assign an ID for verification<br>
• Display stored books only if the ID is correct<br>
• Exit the program using a command<br><br>

🔧 Key Features<br>

• Uses classes and objects<br>
• Demonstrates constructors (__init__)<br>
• Implements static methods for ID verification<br>
• Uses lists to store book data<br>
• Menu-style while loop for continuous interaction<br><br>

🧠 Concepts Covered<br>

• Object-Oriented Programming (OOP)<br>
• Static methods<br>
• Conditional statements (if / else)<br>
• Loops<br>
• User input handling<br><br>

▶️ How It Works<br>

User enters the book name<br>

User provides an ID for verification<br>

If ID matches (1111), books are displayed<br>

Program continues until the user types exit<br><br>

🎯 Purpose<br>

This project is designed to help beginners practice Python fundamentals and understand how real-world systems can be modeled using classes and logic.<br><br>
